# UB-06 Rubric

| Area | Points |
|---|---:|
| Driver returns one correctly identified response per request | 30 |
| Sequence retrieves and type-checks each response | 20 |
| Sequence validates tag and result independently | 25 |
| Test lifetime includes all response checks | 15 |
| Explanation and reproducible evidence | 10 |

Passing requires at least 75 points, three verified responses, and rejection of
the wrong-response fixture.
