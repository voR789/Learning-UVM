# FV-05 Rubric

| Area | Points | Evidence |
|---|---:|---|
| Interface and modports | 25 | All ALU signals are grouped and directions are correct from both perspectives |
| Virtual-interface use | 25 | Class receives, validates, and exclusively uses the intended interface handle |
| Timing and checking | 30 | Drive/wait/sample ownership is deterministic and every output is self-checked |
| Fault detection and diagnostics | 10 | An incorrect expectation produces a useful nonzero failure |
| Reflection | 10 | Learner explains instance, handle, modport, and timing responsibilities |

Passing requires at least 75 points, a normal pass, and deliberate-fault evidence.
