## Termination and reproducibility

- Deterministic test order:
  - FIFO-RST-01
  - FIFO-RST-02
  - FIFO-EMPTY-FULL-01
  - FIFO-EMPTY-RD
  - FIFO-SIM-01
  - FIFO-FULL-RECOVERY-01
  - FIFO-WRAP-01
  - FIFO-GLOBAL-01 remains active as a background check throughout all scenarios.
- Random seed use:
  - Run with seeds 1, 231, and 353.
- Timeout policy:
  - At 3 us, report the active test or scenario and terminate with failure.
- Required check count or completion invariant:
  - All planned test cases have completed.
  - Every expected observation has been processed by the scoreboard.
  - The reference queue is empty.
  - No expected reads or observations remain outstanding.
  - All required assertion checks have passed.
  - All required reachable coverage is complete.
  - `error_count == 0`.
- Failure evidence to retain:
  - Test or scenario name, seed, and simulation time.
  - Differences between actual and expected observations.
  - Remaining coverage holes.
